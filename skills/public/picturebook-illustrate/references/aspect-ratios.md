# Aspect ratios

| 比例 | 像素 | 用途 |
|------|-----------------|------|
| `1:1` | 512×512 | 头像、图标、方形海报 |
| `3:4` | 576×768 | 竖版人像、手机壁纸、书籍封面 |
| `4:3` | 768×576 | 传统照片、PPT |
| `16:9` | 768×432 | 横版视频封面、桌面壁纸 |
| `9:16` | 432×768 | 短视频、Story |
| `2:3` | 512×768 | 摄影、明信片、绘本插页（默认） |
| `21:9` | 896×384 | 电影宽银幕 |

也可同时传 `width` + `height` 覆盖比例预设。
